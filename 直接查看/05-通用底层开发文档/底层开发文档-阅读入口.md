# 通用导入器底层开发文档入口

本目录只解释通用底层，不包含COCO组件文件索引，也不包含完整网站页面清单。

## 阅读顺序

1. `IMPORTER-CORE-DEVELOPMENT.md`
   - 底层目标、正式入口、目录结构、平台适配、页面ID、组件命名、图片证据、错误分类、熔断、并发和故障排查。
2. `AUTOMATED-VALIDATION-PROCESS.md`
   - 公共资源、代表样本、逐组件、逐页面、逐按钮、路由、响应式、可编辑性和全站总验收。
3. `DEVELOPMENT.md`
   - 分层、正式入口、自包含边界、增量闭环、图片恢复、代码质量和浏览器安全。
4. `SHOPIFY-OS20-STANDARDS.md`
   - Shopify sections、theme blocks、schema、settings、presets、模板和编辑器标准研究。
5. `IMAGE-RECOVERY-GATE.md`
   - 图片恢复、失败门禁、证据更新和禁止旧图片问题再次进入正式输出。
6. `CORE-SOURCE-INVENTORY.txt`
   - 通用底层实际交付源码的逐文件清单。

## 通用底层实际代码位置

真实代码位于交付根目录：

```text
03-通用导入器底层代码/
```

核心分层：

- `src/import-core/`：抓取、资源、浏览器、网络、准备状态和基础验证；
- `src/import-foundation/`：页面ID、组件身份、命名、复用、schema、资源合同和发布门禁；
- `src/localization/locale-service.js`：跨网站共享的语言运行时；
- `scripts/importers/`：不同平台适配器；
- `scripts/`：通用构建、路由、图片、组件、页面和全站验证入口；
- `tests/`：底层自动测试。

## 独立验证

通用底层是单独可测试的软件包：

```powershell
cd 03-通用导入器底层代码
npm ci
npm test
npm run check
```

`npm run check` 在纯底层包中执行依赖边界和自包含检查；COCO的TypeScript检查在组合源码工程中执行。
