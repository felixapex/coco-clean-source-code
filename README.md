## 完整网站

完整交付包约 1.94 GiB，已拆成 100 个 20 MiB 分卷，位于 `完整网站分卷`。

在 Windows PowerShell 中运行：

```powershell
.\restore-and-verify.ps1
```

脚本会：

1. 校验 100 个分卷的 SHA256。
2. 合并分卷并校验整包 SHA256。
3. 解压完整交付目录。
4. 根据包内 `SHA256SUMS.txt` 校验全部 27,342 个受管文件。
