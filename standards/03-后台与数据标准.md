# 后台与数据标准

版本：1.1.0  
Owner：后台与数据团队

## 1. 核心实体

站点、主题、模板、区块组、section 实例、block 实例、global settings、revision、发布版本、页面路由、资源文件、产品、变体、分类、菜单、客户、购物车、订单、locale、market 均有稳定 ID、owner、createdAt、updatedAt 和版本信息。

## 2. Revision 与发布

- 所有编辑保存生成不可变 revision。
- Draft 指向候选 revision，Live 指向已发布 revision。
- 发布操作验证 schema、路由、资源 READY 状态和验收结果后原子切换 Live 指针。
- 保存采用乐观并发；`baseRevision` 不匹配返回冲突。
- 迁移记录输入版本、输出版本、映射和结果；失败不得覆盖原数据。

## 3. 文件与媒体

流程：申请短期上传凭证 → 上传临时区 → 校验真实 MIME/大小 → 恶意文件扫描 → 图片重新编码或视频转码 → 生成尺寸/元数据 → READY → 正式引用。

- 状态至少：pending、uploading、processing、ready、failed、quarantined、deleted。
- READY 前禁止发布引用。
- 保存 alt、宽高、比例、焦点、类型、大小、校验和、所有者、引用计数。
- URL 拉取必须防 SSRF，只允许批准协议和可解析公网目标。
- SVG/XML/HTML 默认拒绝；文件名服务端重命名。
- 配额、孤儿文件过期、软删、引用检查和异步物理清理必须可审计。

## 4. 商业数据

- 产品与变体提供价格、比较价、货币、SKU、库存、媒体、option、数量规则、单位价格和 selling plan。
- 购物车 API 负责加购、改量、删除、属性、备注、折扣、税、总计和错误。
- 前端传入价格永远不可信，后台重新计算。
- 账户、结算、支付和订单属于后台阶段，组件只消费合同。

## 5. 隐私与安全

- consent 分 preferences、analytics、marketing、sale-of-data；只有访客明确交互才能写入。
- 非必要处理在需要同意的地区默认关闭。
- 提供数据导出、客户删除/匿名化、店铺删除任务；支持幂等、审计、失败重试和法定保留例外。
- 外部输入按上下文转义；富文本白名单净化；SQL 参数化；状态改变必须认证授权。

## 6. SEO 与发布层

发布层生成 sitemap、robots、canonical 基础 URL 和站点域名配置。sitemap 资源分页必须根据 `hasNextPage`，不能因某页为空提前结束。组件提供页面元数据和 JSON-LD 数据，不自行发布 sitemap。

## 7. 后台门禁

覆盖：权限越权、跨店数据、重复请求、版本冲突、迁移失败、上传伪装、SSRF、恶意文件、配额、引用删除、购物车并发、价格篡改、同意撤回、数据导出和删除、发布原子性与回滚。

## 8. 资源接口合同

申请上传：

```json
{
  "siteId": "site_123",
  "filename": "factory.jpg",
  "declaredMime": "image/jpeg",
  "size": 204800,
  "purpose": "theme_image",
  "checksum": "sha256:..."
}
```

返回 `assetId`、短期 upload URL、过期时间和允许的 headers。完成上传只把资源推进 `processing`；扫描、重新编码和元数据提取成功后才进入 `ready`。

```text
pending -> uploading -> processing -> ready
              |             |-> failed
              |             |-> quarantined
              |-> expired
ready -> soft_deleted -> physically_deleted
```

标准错误：`UPLOAD_EXPIRED`、`FILE_TOO_LARGE`、`TYPE_MISMATCH`、`MALWARE_DETECTED`、`PROCESSING_FAILED`、`QUOTA_EXCEEDED`、`ASSET_IN_USE`。

## 9. 发布接口合同

发布请求必须包含 `siteId`、`draftRevision`、`expectedLiveRevision` 和幂等键。后台依次检查 schema、资源、路由、验收报告和权限，再原子切换 Live。错误至少区分 `REVISION_CONFLICT`、`VALIDATION_BLOCKED`、`RESOURCE_NOT_READY`、`ROUTE_CLOSURE_FAILED` 和 `AUDIT_NOT_PASSED`。
